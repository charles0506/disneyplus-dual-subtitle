# Disney+ 增強（音量＋雙字幕＋字幕放大）

Disney+ 網頁版一支搞定：

- **音量放大**：100%~600%（預設 250%），接壓縮器防爆音、拉近對白和爆炸聲差距
- **字幕放大**：比 Disney+ 原生字幕大，可調
- **雙字幕**：中文上排（粗、大）、英文下排（細、小），貼近畫面底部，暫停時隱藏（排版照自製 Netflix 雙字幕插件）
- **畫質顯示**：左上角顯示目前解析度、約略位元率、清單最高畫質、掉格數（滑鼠移動時出現，Alt+Q 常駐）

安裝：https://raw.githubusercontent.com/charles0506/disneyplus-dual-subtitle/main/disneyplus-dual-subtitle.user.js

先在 Disney+ 播放器選好原字幕（例如中文），腳本會自動抓另一語言。

## 快捷鍵（播放時）

| 按鍵 | 功能 |
|---|---|
| Alt + ↑ / ↓ | 音量 ±25%（也可在右上角膠囊上滾輪） |
| Alt + 0 | 音量增強開／關（也可點膠囊） |
| Alt + = / - | 字幕放大／縮小 |
| Alt + S | 第二字幕開／關 |
| Alt + L | 切換第二字幕語言 |
| Alt + Q | 畫質資訊常駐／只在滑鼠移動時顯示 |
| Alt + D | 顯示狀態（字幕軌、時間差校正、畫質） |

## 做法

- 音量：`<video>` → Web Audio GainNode → DynamicsCompressor。若瀏覽器對 DRM 影片只輸出靜音，
  偵測到連續 8 秒全零會自動停用音量增強並重新整理，之後點膠囊可重新啟用。
- 字幕：側錄頁面載入的 HLS 清單與 WebVTT 字幕分段，自己抓另一語言整軌，
  用原字幕出現時刻比對文字來校正時間差，原生字幕藏起來但照讀文字，和第二語言一起自己畫成兩行。

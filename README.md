# Disney+ 增強（音量＋字幕放大＋畫質）

Disney+ 網頁版一支搞定：

- **音量放大**：100%~600%（預設 250%），接壓縮器防爆音、拉近對白和爆炸聲差距
- **字幕放大**：比 Disney+ 原生字幕大，可調；貼近畫面底部，暫停時隱藏
- **畫質曲線圖**：右上角音量下方顯示目前解析度、約略位元率、清單最高、掉格數，加上解析度隨播放時間的曲線，看多久爬到最高畫質（滑鼠移動時出現，Alt+Q 常駐）
- **鎖定最高畫質**（Alt+H，預設關）：把畫質清單裡低於最高解析度的檔位刪掉，強迫播放器用最高畫質；網速不夠會一直緩衝。重新整理頁面後生效

安裝：https://raw.githubusercontent.com/charles0506/disneyplus-dual-subtitle/main/disneyplus-dual-subtitle.user.js

在 Disney+ 播放器選好要看的字幕語言，腳本會把它放大顯示。

> v1.5.0 起拿掉雙字幕（第二語言字幕對時一直不穩定），字幕放大改成直接放大 Disney+ 當下顯示的那句，不再自己抓字幕檔。

## 快捷鍵（播放時）

| 按鍵 | 功能 |
|---|---|
| Alt + ↑ / ↓ | 音量 ±25%（也可在右上角膠囊上滾輪） |
| Alt + 0 | 音量增強開／關（也可點膠囊） |
| Alt + = / - | 字幕放大／縮小 |
| Alt + Q | 畫質資訊常駐／只在滑鼠移動時顯示 |
| Alt + H | 鎖定最高畫質開／關（重新整理後生效） |
| Alt + D | 顯示狀態（字幕倍率、畫質、主清單來源、鎖定是否生效、實際使用的版權保護） |

## 做法

- 音量：`<video>` → Web Audio GainNode → DynamicsCompressor。若瀏覽器對 DRM 影片只輸出靜音，
  偵測到連續 8 秒全零會自動停用音量增強並重新整理，之後點膠囊可重新啟用。
- 字幕放大：原生字幕藏起來但照讀它當下的文字，自己畫成大字，所以時間永遠跟 Disney+ 一致。
- 畫質：側錄 HLS 主清單的 `#EXT-X-STREAM-INF` 取得各檔位；頁面會看到好幾份主清單（片頭、廣告、下一集），
  用頁面實際載入的字幕分段網址認出正在播哪一份。主清單經 fetch / XHR 傳給播放器時才能鎖定最高畫質。
